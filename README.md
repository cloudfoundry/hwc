# hwc

[![Go Report
Card](https://goreportcard.com/badge/code.cloudfoundry.org/hwc)](https://goreportcard.com/report/code.cloudfoundry.org/hwc)
[![Go
Reference](https://pkg.go.dev/badge/code.cloudfoundry.org/hwc.svg)](https://pkg.go.dev/code.cloudfoundry.org/hwc)

`hwc` is a wrapper around [Hosted Web Core
API](https://msdn.microsoft.com/en-us/library/ms693832(v=vs.90).aspx)
for running .NET Applications on Windows.

>
> This repository should be imported as `code.cloudfoundry.org/hwc`.
